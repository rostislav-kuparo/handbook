# Handbook

Текстовый редактор без привычного форматирования. Вместо жирного и курсива — **ваш почерк**: вы пишете каждую букву столько раз, сколько хотите, а программа собирает из этого живой шрифт, где одинаковые буквы никогда не повторяются. Посреди текста можно вставлять **HTML-блоки** — редактируемые графики, диаграммы и фигуры.

Всё работает локально: без сервера, данные лежат в IndexedDB на этом компьютере. Поддерживаются русские, украинские (і, ї, є) и латинские буквы, греческие буквы и математические знаки для формул.

## Установка (Windows)

Скачайте установщик `Handbook_…_x64-setup.exe` со страницы [Releases](https://github.com/rostislav-kuparo/handbook/releases/latest) и запустите. Права администратора не нужны: программа ставится только для вашего пользователя, а установщик создаёт ярлык на рабочем столе и в меню «Пуск». Удаляется как обычная программа, через «Параметры → Приложения».

Чтобы перенести почерк и документы с другого компьютера или из веб-версии, нажмите в старом месте **«Резервная копия всего»**, затем в новом **«Открыть .json…»** и выберите этот файл.

## Сборка из исходников

Нужно: Node 22+, Rust (`rustup`) с целью `wasm32-unknown-unknown` и `wasm-pack`. Для десктопной версии — MSVC Build Tools и WebView2 (в Windows 11 уже есть).

```bash
npm install
```

```bash
npm run dev
```

Откроется веб-версия на http://localhost:5173. Перед стартом скрипт `scripts/prepare.mjs` сам пересоберёт Rust-ядро в WebAssembly, если его исходники менялись.

```bash
npm run app
```

Запускает настольное приложение (Tauri) с той же веб-частью.

```bash
npm run app:build
```

Собирает установщик Windows (`target/release/bundle/nsis`).

```bash
npm run test:core
```

Запускает тесты ядра (43 штуки). Среди них проверки через HarfBuzz (rustybuzz): чередование вариантов, пары-лигатуры, переход на верхнее соединение после «о», кернинг; а также конец слова без хвостика, разные одиночные буквы в разных абзацах и то, что новые варианты не теряют петлю («е» не становится «с»).

## Как пользоваться

### Почерк → «Буквы и пары»
1. Выберите букву и напишите её на «прописи». Строчные пишутся между линиями «строка» и «строчные», прописные — до линии «прописные», хвосты (д, у, р) — до «хвостов». `Enter` — сохранить и писать ещё, `Ctrl+Z` — отменить штрих, `Esc` — очистить, `←/→` — соседняя буква. Вариантов может быть сколько угодно.
2. Кружки на записанных вариантах — **точки входа и выхода**:
   - зелёный — буква соединяется с соседней;
   - серый — без соединения;
   - жёлтый — соединение включено, но точка не на краю буквы, поэтому оно не сработает.

   Вход — начало первого штриха, выход — конец **последнего**, если там может быть соединение. Иначе берётся другой конец штриха, который подходит: у «А» — низ правой ножки, а не перекладина, у «і» — низ палочки, а не точка (точка никогда не соединяется).

   Если кружок всё же встал не туда, **перетащите его мышью**: пока тянете, подсвечены концы штрихов, и кружок встаёт на ближайший. Клик без перетаскивания по-прежнему включает и выключает соединение.

   В **аббревиатурах** (заглавные подряд — СССР, ПРИВЕТ; буквы у точки — т.е., А.С.) берётся вариант без входа и выхода, и такие буквы не соединяются.

   В редакторе вариант **без точки входа** ставится в **начало слова**, вариант с входом и выходом — в **середину**: если вы написали букву обоими способами, шрифт сам переключается на форму для середины после любой буквы. На миниатюрах это подписано: «начало слова» или «середина».

   **«Отрендерить»** соединяет буквы иначе, как рука: буква остаётся такой, как вы её написали (ничего не подгибается к общим линиям), а от настоящего выхода предыдущей буквы к началу следующей рисуется плавный соединительный штрих. Поэтому в середине слова бывают **все** ваши варианты, в той же пропорции, в какой вы их писали, а не один-единственный «серединный». Буква, написанная без входа, тоже соединяется: штрих идёт к её первому настоящему штриху (не к точке «і», если точку вы ставите первой). Если буква начинается внутри себя (верх овала «а», «d», «о»), штрих заходит поверху. Выход с верхушки высокой буквы или из-под хвоста соединением не считается. Это отключается галочкой в настройках рендера.

   **Конец слова** в «Отрендерить» идёт без хвостика: берётся вариант без выхода, если вы такой писали, а иначе соединительный хвостик укорачивается до короткого росчерка. Однобуквенные слова (і, з, у, а, в) пишутся вариантом без входа и выхода.
3. **Пары букв** (ст, но, ов…) пишутся одним движением. В тексте пара заменяет отдельные буквы и даёт естественную связку. Можно добавить свою пару.
4. Клетки с пометкой «авто» — буквы, которых вы ещё не писали, но движок собрал их из ваших же штрихов:
   - й из и, ё из е;
   - О, С, Х, З, Э из строчных;
   - украинские і ↔ i, ї из і, є из с;
   - латинские и греческие двойники кириллицы (Π из П, Φ из Ф, Γ из Г, Α, Β, Ο, Χ…);
   - знаки препинания и математические знаки вашим пером (+ − × = ≠ ≈ ≤ ≥ ° ⊥ ∥ ∠ △ → ∞ √ π ∑ ∫ …).

   Написанная вами буква всегда заменяет автоматическую.

### Почерк → «Напиши фразу»
Напишите слово целиком, как обычно пишете. «Разметить буквы» ставит границы между буквами автоматически, по местам, где чернил меньше всего, и сразу наклоняет их по наклону вашего почерка. Нижний кружок границы двигает её, верхний наклоняет. Место разреза становится соединяющей точкой выхода у левой буквы и входа у правой. Можно сохранить и пары.

Следующее слово и его регистр (все строчные / с заглавной / ВСЕ ЗАГЛАВНЫЕ) выбираются случайно, но чаще с теми буквами, у которых ещё меньше трёх вариантов. Если сохранять каждое написанное слово, весь алфавит закрашивается примерно за 70 слов. Наборы: русский, Latin, українська и **«Формулы»** — короткие уравнения (α + β = 90°, AB ∥ CD, √16 = 4, A ∩ B = ∅), чтобы написать знаки своей рукой. Кнопки «Аа», «АА», «аа» меняют регистр любой своей фразы.

Сверху студии есть шкала **прогресса**: 100 %, когда у каждой из 66 русских букв (строчных и прописных) есть минимум по 3 варианта.

### Настройки рендера
Они в «Документах», в меню **⚙** рядом с кнопкой «Отрендерить», и меняют вид текста и в редакторе, и в отрендеренном виде.
- **Строки:**
  - «Неровность строк» — разное расстояние между строками;
  - «Просадка» — строка уходит вниз, слова и буквы проседают ниже линейки.
- **Перо и почерк:** толщина, нажим, живость, «фантазия модели» (насколько новые варианты отходят от написанных: при 0 — только ваши варианты, вперемешку), наклон, интервалы, число вариантов в шрифте.
- **Переключатели:** слитное письмо, соединение живым штрихом в рендере, новые варианты по модели, кернинг, пары, достройка недостающих букв.
- Пары берутся только в тех вариантах, что написаны в размер своих букв: пара «на» с высокой, как прописная, «Н» в тексте не появляется (буквы тогда пишутся по одной).

### Документы
Текст пишется на листах **А4** (210×297 мм, поля 20/20/25/15 мм). Что не помещается на лист, переносится на следующий, новые листы появляются сами, как в Word. Это относится и к строкам посреди абзаца, и к блокам. Клик по пустому месту листа ставит курсор в конец текста. Подчёркнутые буквы ещё не написаны: клик по такой букве открывает холст прямо в тексте.

«Вставить блок» добавляет:
- **чертёж** — график или геометрию по командам в стиле GeoGebra (см. ниже);
- диаграмму (столбики тянутся мышью);
- график (точки тянутся);
- схему (фигуры, подписи, стрелки);
- свой HTML.

Меню **«Лист»**: сверху ползунок «Размер букв» (общий для всех документов, рядом видно значение в px), ниже значки вида листа (линейка, клетка, чистый) и готовых полей (обычные, узкие, широкие). Под ними ползунки полей в миллиметрах, **перо чертежей** (ручка или карандаш и цвет, см. «Чертежи»), галочка «Название на листе» (снимите её, чтобы убрать заголовок со страницы), галочка **«Нумерация страниц»** с номером первого листа и цвет чернил: тёмно-синий, чёрный, тёмно-фиолетовый или свой. Всё это хранится в самом документе. Чтобы сделать отдельные слова или строки **крупнее/мельче** или **другим цветом**, выделите их: появится панель с «A− / A+ / 1×» и цветами ручек. Она стоит на месте, пока вы меняете размер. Межстрочный интервал при этом не меняется. Тема приложения переключается кнопкой в правом верхнем углу: как в системе, светлая или тёмная. На тёмной бумаге чернила показываются светлым оттенком того же цвета, а печатаются настоящим цветом.

Меню **«Σ Формулы»**: нижний и верхний индекс (x₂, x², также `Ctrl+,` и `Ctrl+.`), греческие буквы и математические знаки. Знаки, которых вы ещё не писали, рисуются вашим пером автоматически; написанные вами всегда главнее. Формулы в LaTeX вставляются сразу рукописными: текст из ChatGPT, Gemini или Википедии с `$f_1$`, `\(\Pi_1\)`, `$x^2 \le r^2$` превращается в f₁, Π₁, x² ≤ r². Можно и набирать: `$\Pi_1$` станет Π₁, как только закроете знаком `$` (`Backspace` сразу после вернёт исходный текст). Кнопка «Распознать формулы $…$» в том же меню переводит формулы, которые уже лежат в документе. Индексы — те же буквы вашего почерка, только мельче и ниже или выше строки, в отрендеренном виде тоже.

### Чертежи
**Чертёж** рисуется по тексту команд, как во входной строке GeoGebra: `A = (0, 0)`, `f(x) = sin(x)`, `Segment(A, B)`, `Intersect(f, g, 1)`, `Angle(A, B, C)`… Рисует его само приложение: линии от руки вашим пером (толщина и нажим из настроек почерка), подписи, числа на осях и индексы (A₁, x²) — буквами вашего почерка из движка, не шрифтом. Поэтому один и тот же текст всегда даёт один и тот же чертёж, кто бы его ни написал: вы или нейронка.

- **Команды** в шапке блока открывают текст чертежа; он перерисовывается сразу. Строка с ошибкой пропускается и подписывается по-русски («Строка 4: не знаю команду «Segmnt». Может быть, Segment?»), остальное рисуется.
- **? Справка** — окно со всеми командами (по-русски или как в GeoGebra), у каждой живой пример вашим почерком и кнопка «Вставить в чертёж».
- **Запрос для нейронки** в той же справке: опишите, что нарисовать, и скопируйте запрос — к описанию добавится инструкция со всеми командами, правилами и примерами. Ответ нейронки вставляйте в «Команды» целиком: строки ```` ``` ```` и фразы вроде «Вот чертёж:» не мешают, старая запись `Segment[A, B]` тоже понимается.
- **Эпюр (начертательная геометрия):** точка с тремя координатами `A = (2, 1, 3)` — это точка в пространстве, и чертёж становится эпюром Монжа. Приложение само рисует проекции A₁ и A₂, тонкие линии связи и ось x₁₂ с точкой O (ось x — влево, как в учебниках; `XAxis("вправо")` разворачивает). Отрезки, прямые, лучи, векторы и многоугольники из таких точек рисуются проекциями; прямая, перпендикулярная плоскости проекций, превращается на ней в точку. `Projections(1, 2, 3)` добавляет профильную проекцию A₃ с осями y, z и постоянной прямой под 45°. `Distance(A, B)` даёт натуральную величину отрезка. Плоскости и тела GeoGebra 3D (`Plane`, `Prism`…) пока не рисуются — плоскость задаётся треугольником `Polygon(A, B, C)`; об этом говорит и сообщение об ошибке, и инструкция для нейронки.
- **Чертёж прямо в тексте:** строка ```` ``` ````, ниже команды, и снова ```` ``` ```` (в русской раскладке та же клавиша печатает `ёёё` — так тоже можно; подходит и `~~~`). Как только закрывающая строка допечатана, кусок становится чертежом, Backspace сразу после возвращает текст. Так же срабатывает вставка: можно вставить в документ ответ нейронки целиком — код станет чертежом, пояснения останутся текстом (и при вставке простым текстом с ```` ``` ````, и когда ответ выделен в чате мышью). Для уже написанного — «Вставить блок» → «Найти чертежи в тексте». Код с меткой другого языка (```` ```python ````) и обычный текст между ```` ``` ```` не трогаются: без метки кусок становится чертежом, только если почти все строки — работающие команды.
- Окно подбирается само, чтобы всё было видно; оси появляются, когда на чертеже есть графики. Окружности всегда круглые: если на чертеже есть фигуры, масштаб по осям одинаковый.
- **Подписи не ложатся на линии.** У каждой подписи много мест вокруг точки, на трёх расстояниях; берётся ближайшее, где нет ни линии, ни другой подписи, и первыми места выбирают подписи в самых тесных углах. Числа на осях переходят на другую сторону оси, если их место занято. Точки в одном месте (A₂ и B₂ проецирующей прямой, Qx₁ и Qx₂) получают одну подпись «A₂ ≡ B₂», как в учебниках.
- **Ручка или карандаш.** В меню «Лист» выбирается, чем рисуются все чертежи документа, а кнопка «✒ Ручка ▾» в шапке чертежа — для одного чертежа. Карандаш рисует тоньше и серым графитом, с зерном бумаги; цвет линий можно выбрать любой. Подписи пишутся тем же пером, галочка «Подписи — ручкой» оставляет их чернилами, как текст. Объекты, которым в командах задан `SetColor`, сохраняют свой цвет.
- **Линии** настраиваются там же ползунками: **кривизна** (0 — как по линейке, больше — сильнее от руки), **толщина** относительно пера почерка, **нажим** (насколько толщина «дышит» вдоль линии) и **заход за концы**. «Сбросить линии» возвращает всё к перу почерка.
- Чертёж попадает в «Отрендерить», печать и постраничный экспорт PNG/SVG как настоящие чернила.

Команды живут в одном списке ([src/sketch/commands.ts](src/sketch/commands.ts)): из него же собираются справка и инструкция для нейронки, так что нейронке не обещают команд, которых нет.

Кнопка **«⇱ Поверх»** в шапке блока кладёт его поверх текста: блок можно тащить за шапку куда угодно по листу и менять ширину за уголок, текст под ним не сдвигается. «↧ В текст» возвращает блок в поток.

Кнопка **«Отрендерить»** рисует текст ручкой: каждая буква уникальна, а строки неровные, как на бумаге. Пока он рисуется, видна шкала прогресса. Текст раскладывается по листам А4, печать в PDF идёт по листу на страницу.

**Экспорт:** PDF (через печать), PNG, SVG, ваш шрифт `.ttf`, документ `.json`. PNG и SVG сохраняются **отдельным файлом на каждый лист** («Конспект — лист 1.png», «— лист 2.png»…): те же буквы, переносы и разрывы страниц, что и в отрендеренном виде. Если у документа выбрана линейка или клетка, она сохраняется вместе с текстом, и в PNG/SVG, и при печати; на «чистом листе» линий нет. После экспорта вверху справа появляется кнопка **истории экспорта**. В настольном приложении файлы ложатся в папку «Загрузки», а из истории их можно открыть или показать в папке.

«Открыть .json…» в списке документов загружает обратно документ, файл почерка или резервную копию всего. «Резервная копия всего» сохраняет одним файлом почерк, все документы и настройки.

## Архитектура

```
Браузер / WebView (TypeScript, React)
├─ Студия: буквы и пары, режим «фраза» (разметка границ) ── штрихи {x, y, t, p}
├─ Редактор (Tiptap/ProseMirror): paragraph | text | htmlBlock (в тексте или поверх)
│     ├─ шрифт "HandbookHand", собирается на лету
│     ├─ плагин страниц: листы А4, переносы строк и блоков через невидимые отступы
│     └─ плагин просадки: сдвиги строк, слов и букв (position: relative)
├─ HTML-блоки ── <iframe sandbox="allow-scripts"> + postMessage SDK
├─ Чертежи (src/sketch): команды → сцена → линии пером + подписи через движок → SVG
├─ Web Worker ──► glyph-core (Rust → WebAssembly)
│                  ├─ synth: подготовка штрихов, соединения на двух высотах, адаптация входа
│                  ├─ shape_model: обучаемая модель формы (PCA по вашим вариантам)
│                  ├─ derive: достройка недостающих букв и знаков
│                  ├─ outline: контуры пера (union капсул через i_overlay)
│                  ├─ kern: оптический кернинг по профилям чернил
│                  ├─ font: TrueType + GSUB (пары, чередование, входы) + GPOS (кернинг)
│                  └─ engine: кэш по буквам, рендер с сидами от слов
└─ IndexedDB (Dexie): samples, documents, settings

Tauri (src-tauri) — тонкая настольная оболочка над той же веб-частью.
```

### Модель данных

```ts
interface Sample {
  id: string;
  char: string;                 // буква, или 2–3 буквы для пары («ст»)
  strokes: { x; y; t; p }[][];  // единицы шрифта: 1000/em, y вверх, строка = 0
  entry: Anchor | null;         // откуда перо приходит от предыдущей буквы
  exit: Anchor | null;          // где перо уходит к следующей
  pointerType: string;          // pen | mouse | touch (для мыши нажим по скорости)
}
interface Anchor { x: number; y: number; connect: boolean }
```

Высота точки определяет **уровень соединения**:
- **нижний** — у строки, как у большинства букв;
- **верхний** — на высоте строчных, как после «о» и «в».

Движок находит обе линии соединения по вашим точкам (медианы) и подгибает к ним концы штрихов. Если буква уходит сверху, а следующая обычно входит снизу, у следующей подставляется вариант со входом сверху: подводящий штрих обрезается там, где он достигает верхней линии. В обратном случае достраивается подъём от строки.

### Откуда «бесконечность» вариантов
- **Обучаемая модель.** Ваши варианты одной буквы, написанные одинаково (то же число штрихов, те же соединения), выравниваются, и PCA находит, *в чём именно* они у вас различаются. Например, петля больше — и хвост длиннее. Новые варианты сэмплируются из этого распределения, «фантазия» масштабирует разброс. Всё считается локально, за миллисекунды.
- **Шрифт.** На каждую букву N вариантов: сначала ваши, потом сгенерированные. Правило `calt` выбирает вариант по предыдущему глифу (`(prev + сдвиг) mod N`), поэтому повторы «ааааааа» всегда разные.
- **Новый вариант растёт из написанного:** берётся один из ваших вариантов и сдвигается по выученным направлениям, а не строится от «среднего» всех вариантов (среднее петель разного размера — это уже не петля, «е» превращалась в «с»). Если вариант всё же потерял петлю или поменял пропорции, вместо него берётся ваш.
- **«Отрендерить»** синтезирует каждую букву заново. Случайность задаётся самим словом и тем, сколько раз оно уже встречалось в документе выше, поэтому «1.» или «і» в каждом абзаце разные, а правка одного слова не перетасовывает остальные.
- Если две соединённые буквы всё же налезают друг на друга, соединительный штрих дотягивается настолько, чтобы буквы разошлись.
- Тексту нельзя задавать CSS `letter-spacing`: браузеры тогда выключают `calt`.

### Безопасность HTML-блоков
Блок работает в `iframe sandbox="allow-scripts"` **без** `allow-same-origin`: у него нет доступа к редактору, IndexedDB и cookie. CSP внутри фрейма запрещает сеть. rough.js и Chart.js встраиваются прямо в `srcdoc`, только если код их упоминает. Связь с редактором — только через `postMessage`, и редактор принимает три типа сообщений от «своего» фрейма.

| SDK | |
|---|---|
| `block.data` | данные (хранятся в документе отдельно от кода) |
| `block.onData(cb)` | подписка на изменения (в том числе на Undo) |
| `block.setData(d)` / `block.update(fn)` | сохранить данные |
| `block.onFont(cb)`, `block.font`, `var(--hand)` | шрифт с почерком |
| `block.ink`, `var(--ink)` | цвет чернил текущей темы |

## Ограничения и что дальше
- **Модель формы — статистическая (PCA), а не нейросеть.** Она хорошо варьирует то, что вы написали, но не умеет придумать букву, которой у вас нет: для этого нужна сеть, заранее обученная на большом корпусе почерков. Недостающие буквы сейчас собираются по правилам из ваших штрихов.
- Разметка во «фразе» режет вертикальными линиями: хвост, который заходит под соседнюю букву (д, у), может отрезаться. Границы можно поправить вручную.
- Просадка в редакторе — визуальный сдвиг. В очень длинных документах (десятки тысяч символов) пересчёт может быть заметен.
- Синхронизация между устройствами, CRDT и нативные диалоги сохранения в Tauri пока не сделаны.
