# Новый интерфейс: план переработки

Цель — минималистичный и «воздушный» интерфейс. Верхней панели больше нет. Всё, что от неё осталось, переезжает в меню окна, в парящие блоки и в правый нижний угол. Подсказки уходят из рабочих экранов в «Информацию». Фоновые полосы и рамки панелей исчезают, скроллбары тоже. Места, где я предлагаю отступить от вашего описания или добавить что-то своё, помечены **⚑**.

## Как будет выглядеть

Документы:

```

│ Файл   Настройки   Информация                           │   ← меню окна (родное)
│                                                         │
│  ╭ Недавние ─────╮      ┌───────────────┐         ╭───╮ │
│  │ Конспект      │      │               │         │ ⊞ │ │   блок
│  │ 27.10, 18:40  │      │     лист      │         │ ▭ │ │   лист
│  │ Начерталка    │      │               │         │ Σ │ │   формулы
│  │ 26.10, 21:05  │      │               │         │───│ │
│  ╰───────────────╯      │               │         │ ✒ │ │   отрендерить / редактировать
│                         │               │         │ ⚙ │ │   настройки рендера
│                         └───────────────┘         ╰───╯ │
```

## Ключевые решения

1. **Меню окна — родное меню Windows.** Это возможно. Полоса «Файл · Настройки · Информация» встаёт под заголовком окна, как в классических программах: Alt и горячие клавиши работают, а тёмная тема поддерживается (в `muda` 0.20, на котором Tauri строит меню, есть тёмная полоса меню для Windows). Меню собирается прямо из TypeScript через `@tauri-apps/api/menu` (`Menu.new`, `setAsAppMenu`). Пункты вызывают обычные функции приложения, Rust почти не меняется, а нужные разрешения уже входят в `core:default`.
   - **⚑ Альтернатива, которую я не рекомендую:** своя полоса заголовка (`decorations: false`), в одной строке с меню и своими кнопками «свернуть/развернуть/закрыть». Выглядит ещё чище, но в Windows 11 пропадёт меню привязки окон (Snap Layouts) при наведении на «развернуть», а кнопки окна, перетаскивание и двойной клик придётся писать и отлаживать самим.
   - В браузере (`npm run dev`, тестовый порт 5174) родного меню нет. Там то же меню рисуется тонкой HTML-строкой из того же описания пунктов: проверять всё можно и без Tauri.

2. **Тема рамки окна следует за темой приложения.** Сейчас при «Тёмной» теме и светлой Windows заголовок окна остаётся светлым. При смене темы вызывается `getCurrentWindow().setTheme('dark' | 'light' | null)`, и заголовок с полосой меню перекрашиваются вместе с приложением. Нужно разрешение `core:window:allow-set-theme`.

3. **Одно описание меню, одна шина команд.** Пункты меню (`file.new`, `file.open`, `file.backup`, `theme.dark`…) описаны в одном месте, в `src/shell/menu.ts`. Действия «Новый документ», «Открыть…», «Резервная копия» уходят из `Documents.tsx` в модуль `src/shell/fileActions.ts`. `Documents` только подписывается на событие «открыть документ id» — так же, как кнопка загрузок уже слушает `EXPORTED_EVENT`. Если команда пришла на вкладке «Почерк», приложение сначала переключается на «Документы».

4. **Иконки — свои SVG в одном файле** `src/ui/icons.tsx`: 20 px, линия 1,6, `currentColor`, в стиле уже существующих `DownloadIcon` и `PageIcon`. Без новых зависимостей. У каждой иконки есть всплывающее название и горячая клавиша (`title`, `aria-label`).

5. **«Парящие» блоки — два токена в `:root`:** `--float` (цвет карточки, чуть прозрачный, с `backdrop-filter: blur`) и `--float-shadow` (мягкая широкая тень), скругление 16 px, без рамок в 1 px. Фон всего окна — один `--desk`. Полосы `--panel` с рамками у `.doc-list`, `.alphabet`, `.side`, `.panel` и градиент под `.toolbar` удаляются. Лист бумаги остаётся как есть.

6. **Скроллбары скрыты везде**, прокрутка колесом, тачпадом и пером остаётся: `scrollbar-width: none` и `::-webkit-scrollbar { display: none }` глобально. **⚑** Чтобы было видно, что ниже есть ещё, края прокручиваемых карточек мягко тают (`mask-image` с градиентом), но только когда содержимое не помещается.

## Меню окна

```
Файл                                   Настройки               Информация
  Новый документ          Ctrl+N         ● Тема как в системе    Как писать буквы
  Открыть…                Ctrl+O           Светлая тема          Команды чертежа и запрос для нейронки
  ─────────────                            Тёмная тема           Горячие клавиши
  Резервная копия всего…                                         ─────────────
  ✓ …со столами (фото)                                           О программе
  ─────────────
  Сохранить почерк…
  Загрузить почерк…
  ─────────────
  Печать / PDF            Ctrl+P
  ─────────────
  Выход
```

- «Открыть…» понимает, как и сейчас, любой .json Handbook: документ, почерк или резервную копию.
- «Загрузить почерк…» переезжает из правой панели «Почерка» и, как сейчас, спрашивает «заменить или добавить».
- Галочка «со столами» хранится в настройках, а не только до перезапуска, как сейчас.
- **Горячие клавиши меню перехватывают нажатие раньше редактора**, поэтому Ctrl+, и Ctrl+. (индексы), Ctrl+Z и другие клавиши редактора в меню не используются.
- «Печать» неактивна на вкладке «Почерк» и когда документ не открыт.
- «Как писать буквы» — новая страница справки (такое же окно, как у справки по чертежам). В неё переезжают все подсказки, убранные из «Почерка», так что ничего не теряется.
- «О программе»: версия, ссылка на GitHub, где хранятся данные и как перенести их резервной копией.
- **⚑ По желанию:** название окна «Конспект — Handbook» с названием открытого документа (`setTitle`, разрешение `core:window:allow-set-title`). Раз заголовок окна остаётся единственным местом с названием программы, он может заодно показывать, что открыто.

### Этап 1. Меню окна

- `src/shell/menu.ts`: описание пунктов, сборка родного меню (`Menu`, `Submenu`, `MenuItem`, `CheckMenuItem`, `PredefinedMenuItem`) и HTML-строка для браузера.

- Тема: `ThemeToggle` удаляется. Три пункта «Настройки» с галочкой на текущем, хранение в `localStorage` как сейчас, плюс `setTheme` для рамки окна.
- «Информация»: «О программе», «Горячие клавиши», «Как писать буквы» (пока с текстами, перенесёнными из «Почерка»), «Команды чертежа» (существующий `SketchHelp`).
- `src-tauri/capabilities/default.json`: добавить `core:window:allow-set-theme` (и `allow-set-title`, если берём название документа в заголовок).

### Этап 2. Без верхней панели

- Из `App.tsx` уходит `<header className="topbar">` целиком: логотип, «Handbook», вкладки, статус шрифта, кнопка загрузок, тема.
- **Парящий угол** справа снизу (`position: fixed`, отступ 16 px): `[⇪ Экспорт] [⤓ Загрузки] ( Документы | Почерк )`.
  - Пилюля вкладок — та же, что сейчас, только парящая.
  - Загрузки (`ExportsButton`) появляются после первого экспорта, как сейчас; история теперь раскрывается вверх.
  - **Экспорт зависит от вкладки.** В «Документах» — всё нынешнее меню «Экспорт» (печать/PDF, PNG, SVG, на столе (фото), шрифт .ttf, документ .json). В «Почерке» — шрифт .ttf и почерк .json. Меню раскрывается вверх.
- **⚑ Статус шрифта.** Надпись «букв в почерке: 210» убирается. Пока шрифт собирается, на «Почерке» в пилюле пульсирует точка, а число букв видно во всплывающей подсказке пилюли и в полосе прогресса «Почерка».
- Нижние ~72 px окна не закрываются содержимым: у листа и правых карточек «Почерка» появляется отступ снизу.

### Этап 3. Документы

- **«Недавние»** — парящая скруглённая карточка слева вместо панели во всю высоту. Внутри только заголовок «Недавние», список (название вашим почерком и дата) и ✕ при наведении. Кнопки «+ Новый документ», «Открыть .json…», «Резервная копия всего» и галочка уходят в «Файл». Высота карточки — по содержимому, но не выше окна, лишнее прокручивается без скроллбара. Подсказка «Почерк ещё пуст…» остаётся одной короткой строкой и только пока почерк пуст.
- **Правая колонка иконок** вместо `.toolbar` над листом: парящая вертикальная карточка у правого края, по центру высоты.
  - ⊞ Вставить блок, ▭ Лист, Σ Формулы — те же меню (`details.menu`), только раскрываются влево от колонки и выравниваются по своей кнопке.
  - Разделитель, затем ✒ Отрендерить / ✎ Редактировать (иконка меняется, включённое состояние залито акцентом) и ⚙ настройки рендера.
  - Текст на кнопках исчезает, названия переезжают во всплывающие подсказки. Содержимое самих меню не меняется, но в меню блока справка по чертежам сжимается до одной строки (она есть и в «Информации»).
- Лист центрируется в оставшемся месте между «Недавними» и колонкой.
- **⚑** При ширине окна меньше ~1150 px «Недавние» сворачиваются в иконку списка (у листа 794 px, а минимальная ширина окна 900 px).

### Этап 4. Почерк

- **Убрать подсказки:**
  - `Hint` (три текста про строчные, прописные и пары) — в «Как писать буквы»;
  - «пишите сколько угодно — каждый вариант…» → остаётся только «· 4»;
  - длинный абзац про кружки входа и выхода — в справку, а у самих кружков короткие подсказки при наведении («вход: соединяется», «выход: не на краю»);
  - «Модель выучила направлений…» → короткая метка «модель: 3» с подсказкой при наведении;
  - примечание «Интервалы… в меню ⚙» в «Стиле букв»;
  - подсказки «Напиши фразу» (про язык и этапы) — бледной надписью-заглушкой внутри пустого холста, а не абзацем над ним.
  - **⚑** Те же пояснения есть в ⚙ настройках рендера («Меняют вид текста…», «Чтобы текст не был написан по линеечке»). Предлагаю убрать и их — для единого вида.
- **Левая карточка алфавита** показывает не все группы подряд, а одну «полку». Внизу карточки две пилюли:
  - `( аа | АА )` — строчные / прописные;
  - `( Кир | Lat | ∑ )` — кириллица / латиница / символы.

  | полка | строчные | прописные |
  |---|---|---|
  | Кир | а–я, і ї є, пары букв, свои пары | А–Я, І Ї Є |
  | Lat | a–z | A–Z |
  | ∑ | цифры, знаки, формулы, «Ещё символы» (регистр неактивен) | — |

  Стрелки ← → ходят внутри полки. Если буква открылась иначе (например, из текста), пилюли сами встают на её полку.
- **Категория «Ещё символы»** на полке ∑ — всё, что программа умеет вставлять или писать, но чего нет в «Почерке»:
  - знаки меню «Формулы» (∉ ⊂ ∪ ∩ ∅ ⇒ ⇔ ∑ ∫ ∀ ∃ ≡ ÷ Π Φ…);
  - знаки, в которые превращается LaTeX (`tex.ts`: ϑ ψ ℝ ∂ ∇ ∏ ⟨ ⟩ ⌊ ⌋ …);
  - любые знаки, которые вы уже дописали в документе через «кликните, чтобы дорисовать», если их нет в других группах.

  Список собирается автоматически из этих источников (общий `src/model/symbols.ts` для меню «Формулы» и алфавита плюс экспорт таблиц из `tex.ts`), так что новые знаки будущих версий появятся там сами. Ненаписанные показаны пунктиром, как сейчас.
- **Правая колонка**: «Проба пера» и «Стиль букв» — отдельные парящие карточки без рамок. Карточка «Резервная копия» уходит в «Файл» и в «Экспорт».
- Переключатель «Буквы и пары / Напиши фразу» и полоса прогресса остаются, но становятся тоньше и без фоновой подложки.

## Проверка

- Каждый этап — в тестовом окне браузера (порт 5174, не трогая данные 5173) и в `npm run app`, где есть родное меню.
- Все пункты меню, включая горячие клавиши, на обеих вкладках. Ctrl+, и Ctrl+. по-прежнему ставят индексы.
- Тема: «как в системе / светлая / тёмная», вместе с рамкой окна и меню.
- «Ещё символы»: знак, дописанный в тексте через всплывающее окно, появляется в категории; знак из «Формул» без образца виден пунктиром.
- Окно 900×600: ничего не перекрывает лист и холст, угол с пилюлей не закрывает кнопки.

## Нужно решить

1. **Меню окна:** родное меню Windows (рекомендую) или своя полоса заголовка в одну строку с меню.
2. **Вторая пилюля в «Почерке»:** я понял её как «Кириллица | Латиница | Символы» (три положения). Если имелось в виду другое (например, только «Латиница | Символы» и отдельно кириллица), поправьте.
3. **Экспорт и загрузки:** в парящем углу рядом с пилюлей вкладок (как в плане) или внизу правой колонки иконок.
4. Убираем ли заодно пояснения в ⚙ настройках рендера (**⚑** в этапе 4).
